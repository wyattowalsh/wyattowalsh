### `generate()` pipeline (`scripts/art/ferrofluid.py:786-1437`)

Contract matches `scripts/art/AGENTS.md`: `generate(metrics, *, seed, maturity) -> str`. Extra kwargs: `timeline=True` (**module default**), `loop_duration=60`, `reveal_fraction=0.93`. **CI/GIF path forces `timeline=False`.** Unlike Ink Garden (`timeline=False` default), a bare local `generate(metrics)` enables SMIL reveal.

1. `resolve_render_metrics(metrics)` then `build_style_dialect("ferrofluid", metrics)` (`796-797`).
2. Maturity: explicit or `compute_maturity`. **`maturity_hint = 1.0` if timeline else `mat`** (`798-800`). Published GIFs take the real snapshot maturity into `_compute_ferrofluid_signals`.
3. World via `compute_world_state` (`803`). Lighting angle from `world.time_of_day` (`1036-1037`). Background is **hardcoded** near-black OKLCH, not the world palette (`1077-1087`).
4. Seed: `visual_seed` prefers `seed` / `label` / `login` / `account_created` (`805-817`). Dipole x is identity-stable when seed is omitted ([`tests/test_ferrofluid.py:935-950`](../../../tests/test_ferrofluid.py)).
5. Repos: `order_repos_for_visual_plan` → `select_primary_repos(..., limit=CFG.max_repos)` (`827-837`). `limit` is ignored ([`scripts/art/shared/visual.py:162-173`](../../../scripts/art/shared/visual.py)); every named repo becomes a dipole. `CFG.max_repos=10` is only a density baseline for `_dense_repo_signal`.
6. `_compute_ferrofluid_signals` (`843-848`, definition `245-522`): composite `field_gain` / `fluid_response` / `surface_tension` / `max_spikes` / `dipole_lift` from stars, forks, traffic, streaks, **and** `extract_accretion_channels`.
7. **Dipole placement** (`903-1006`): `repo_to_canvas_position(..., strategy="language_cluster")` into a canvas of `WIDTH × pool_y*0.9` (`910-913`). Then a small x-bias and y-lift. Then **`_spread_positions` on x only** (`994-1006`).
8. Field: vectorised `moment / r²` on a `grid_resolution=60` mesh above the pool (`528-553`, `1008-1016`). Ramp is `signals.field_gain * dialect.knobs["field_gain"]` — **two different `field_gain`s multiplied**.
9. Spikes where `field > b_crit`; heights `∝ sqrt(field - b_crit)` then `*= dialect.knobs["spike_scale"]` (`1018-1033`). Strongest cells, painter-sorted (`567-598`). Uncovered owners get `ferro-capillary` stubs (`1186-1266`).
10. SVG: defs/gradients → dark bg → pool line at `HEIGHT * 0.55` = **440** → reflections → `ferro-spike` polygons **rooted at `pool_y`**, not at dipole y (`1338`) → highlights → `#ferro-ripples` → `ferro-dipole` circles **also at `pool_y`** (`1404-1432`) → `dialect_group_markup` (`1435`).

Config ([`ferrofluid.py:48-67`](../../../scripts/art/ferrofluid.py)): `max_repos=10`, `max_elements=25000`, `grid_resolution=60`, `moment_base=500`, `b_critical=0.3`, `spike_scale=80`, `spike_base_width=8`, `pool_y_fraction=0.55`, `_DIPOLE_MIN_GAP=44`.

### Why dipoles cluster (A1 leftover)

Root cause is **language-family placement**, not missing dipoles.

`repo_to_canvas_position(..., strategy="language_cluster")` ([`scripts/art/shared/visual.py:211-248`](../../../scripts/art/shared/visual.py)) maps language → family → quadrant:

| Family | langs (subset) | `(cx_frac, cy_frac)` |
|---|---|---|
| data | Python, Jupyter, R | **(0.25, 0.30)** |
| systems | Go, Rust, C, C++ | **(0.25, 0.70)** |
| web | JS/TS/HTML/CSS | (0.75, 0.25) |
| scripting | fallback / unknown | (0.50, 0.50) |

Python and Go share **the same x-fraction 0.25**. The accretion fixture alternates Python/Go ([`tests/test_living_art_media.py:1153-1154`](../../../tests/test_living_art_media.py)); they still pack on the **left third**. Same-language repos jitter inside one quadrant (`jitter=0.15`).

Post-placement mitigations that do **not** create towers:

1. **`_spread_positions`** (`70-102`, applied `994-1006`) pushes **x** apart with `min_gap = max(44, WIDTH*0.055) = 44`, order-preserving. Same-language repos remain a **contiguous pack**. 44 px on an 800 canvas is **22 px at the 400×400 GIF**. Field cells are ~13 px (`800/60`); spike bases ~8 px; superposition still merges neighbors into one hedge.
2. **Y is not a tower axis.** Dipole `y` feeds the field (`data-depth` on the marker) but spikes and dipole *circles* are drawn on the pool line (`1338`, `1427-1428`). The picture is a 1D skyline.
3. **Nearest-dipole coloring** (`601-610`, `1117`) assigns overlapping field peaks to whichever magnet is closer. Close same-language dipoles share one ridge and one hue (`LANG_HUES["Python"]=215`).
4. **Capillaries** (`1186-1266`) are ~10 px stubs, not a second tower.

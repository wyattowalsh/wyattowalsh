```1094:1108:scripts/art/ink_garden.py
def generate(
    metrics: dict[str, Any],
    *,
    seed: str | None = None,
    maturity: float | None = None,
    timeline: bool = False,
```

## Maturity / t0 gate

### Clock vs staging

`compute_maturity` (`world_state.py:167-195`) is a smoothstep mix of log-scaled commits, stars, last-year contribs, followers, repo count, max age, forks, network. Early spine `1/2/20/1` computes **~0.012**. t1 `2/24/400/18` ~0.25; t2 `4/120/2400/80` ~0.53.

Per-tree stagger (`ink_garden.py:1528-1612`):

| Symbol | Value / rule |
|---|---|
| `RAMP` | `0.15` |
| `first_start` | `0.03` |
| `tree_start` | index stagger, or chronological `repo_growth_order` × span |
| `tree_t` | `clamp((mat - tree_start) / tree_ramp)` |
| skip | `tree_t <= 0` **or** (`chronological_growth` and `tree_t < 0.05`) |
| rescue | if skip: `tree_t = max(tree_t, 0.34)` when `show_existing_world` **or** `is_oldest`; else `continue` |

```1605:1612:scripts/art/ink_garden.py
        # Snapshot worlds (daily spine / computed maturity) keep existing
        # repos visible; explicit maturity staging still hides later trees.
        show_existing_world = timelapse_contract or maturity is None
        if tree_t <= 0.0 or (chronological_growth and tree_t < 0.05):
            if show_existing_world or is_oldest:
                tree_t = max(tree_t, 0.34)
            else:
                continue
```

**Three behaviors:**

| Caller | `maturity=` | `timelapse_contract` | What you see |
|---|---|---|---|
| Daily GIF (`_render_single_frame`) | snapshot (~0.01 at t0) | **True** | every repo **in that snapshot** drawn at `tree_t ≥ 0.34` |
| A1 / tests that omit `maturity` | `None` → compute | False | same rescue (`maturity is None`) |
| Animate / `test_dated_growth_prefers_older_*` | explicit 0.24 etc. | False | **later dated repos hidden**; only oldest rescued |

`is_oldest` rescue means **current** `generate()` draws ≥1 `repo-tree` whenever the metrics list contains ≥1 named repo — even `maturity=0.0`. Probe (2026-08-18): A1 spine t0 `1/2/20/1` → **1 plant**; empty `repos=[]` → **0 plants**; `MINIMAL_METRICS` at `maturity=0.0` → **1 plant**.

### Secondary gates (make t0 look empty even when a group exists)

Chronological leaf/bloom/detail gates (`ink_garden.py:1636-1675`): default `leaf=0.20`, `bloom=0.48`, `detail=0.68` (fresh repos even later). A rescued `tree_t = 0.34` **fails the bloom gate**, so first-repo frames are stem/soil, not flowers.

Non-chronological path sets those gates to `0.0` (`1660-1662`), so undated repos bloom earlier.

Also gated on `mat` itself (no plants required): webs `mat > 0.25` (`2723`), ambient seeds `mat > 0.2` (`2730`), samaras `mat > 0.35` (`2748`). t0 `mat ≈ 0.012` skips all three.

`timeline=True` bypasses the growth clock (`mat = 1.0`) and reveals via SMIL delay. **Not** the published GIF.

## Four-channel visual encoding

Shared knobs (`accretion.py:166-175`):


**Leaks / landmines for Dig1:**

- Firefly count is `max(star_velocity, glint_count)`. Stars can light glints without followers. Isolation tests must pin `star_velocity`.
- A **second** firefly layer (`firefly_elements(star_velocity)` `4332:4344`) is stars-only, not followers.
- Knobs are **not** serialized as `data-bloom-scale` / `data-trunk-scale` / `data-glint-count`. Root only has `data-accretion-*` scales (`StyleDialect.svg_attrs`, `accretion.py:129-143`). Other dialects (topo `data-ripple-gain`, etc.) expose extra knob attrs; inkgarden does not.
- Overlay is always drawn, including on the empty A1 t0 still. Overlay-yes / garden-no is the unreadability leftover.
- Species table `SPECIES` (`89:175`) has oak/birch/conifer/shrub/wildflower/wisteria/banyan. **fern / bamboo / seedling** are special-cased in `generate()` and absent from `SPECIES`. Do not `SPECIES[species]` blindly.

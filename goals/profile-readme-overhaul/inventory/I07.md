`tests/test_skills.py` `test_skills_yaml_badges_have_https_hrefs_and_camo_safe_urls` requires every catalog `.url` to be non-empty `https://` and forbids Wikipedia hosts. It zips skill **names** to first-party board `<img alt>` / `src=".github/assets/img/readme/tech-*.svg"`. It does **not** zip YAML `url` to a rendered `<a href>` — `_render_all` / `_render_category` emit unlinked chip boards. `_render_badge` can wrap a homepage but is unused on the shipped path. `SkillEntry.url` is still `str | None` and the validator allows `http://`.

## Finding

Every catalog skill has an https homepage and `slug` or `logo_path` (or both). Those urls are catalog data, not README hrefs.

## Gap

fact-badges-stack / fact-badges-qa on the shipped surface: no 151-way YAML `url` ↔ README `<a href>` zip; boards have no per-skill homepage links and no retro icons at badge size. Live github.com/camo QA of every shield is absent (`test_github_dev_readme_camo_renders_skill_icons` skips when origin/dev HTML has no Camo skill images).

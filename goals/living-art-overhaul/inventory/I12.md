### `generate()` pipeline (`scripts/art/physarum.py:822-1604`)

Contract matches `scripts/art/AGENTS.md`: `generate(metrics, *, seed, maturity) -> str`. Extra kwargs: `timeline=True` (default), `loop_duration=60.0`, `reveal_fraction=0.93`. **CI/GIF path forces `timeline=False` and passes snapshot maturity.**

1. `resolve_render_metrics(metrics)` then `build_style_dialect("physarum", metrics)` (`846-847`).
2. Maturity: explicit override or `compute_maturity`.  
   `explicit_snapshot = maturity is not None`  
   `growth_mat = 1.0 if timeline_enabled and not explicit_snapshot else mat` (`849-852`).  
   Standalone SMIL (`timeline=True`, no maturity) draws the **full** organism. Published GIFs take the **low-maturity fade path**.
3. World palette via `compute_world_state` + `_build_world_palette_extended` (`855-861`). Unused for substrate: background is hardcoded `_BG_COLOR = oklch(0.12, 0.04, 250)` (`118`, `1407`).
4. Seed hash + numpy RNG (`869-870`).
5. Repos: `order_repos_for_visual_plan` → `select_primary_repos(..., limit=CFG.max_repos)` (`875-912`). `select_primary_repos` **ignores `limit`** and returns the full ordered set ([`scripts/art/shared/visual.py:162-173`](../../../scripts/art/shared/visual.py)). `CFG.max_repos=10` / `MAX_REPOS=10` are density baselines, not a cap. Confirmed by `test_physarum_prefers_full_repo_set_over_truncated_top_repos` (12 cores from 12 repos).
6. Timeline window + daily series (`959-1044`). `_fade(start, full)` ramps on `growth_mat` (`864-866`).
7. Food sources: one nutrient node per repo at `repo_to_canvas_position(..., strategy="language_cluster")`. Concentration `conc` includes age, per-repo stars, affinity, PR boost, recency, visibility, **and `dialect.knobs["nutrient_scale"]`** (`1134-1172`). Optional satellites (`1186-1227`).
8. Agent count from maturity + activity/commit/ecosystem signals, then **`+ int(round(36 * dialect.knobs["vein_gain"]))`** (`1229-1254`). Floor 12 or 24 agents; cap 2000.
9. Evaporation, `sim_steps` in `[12, 240]`, speed, contour levels (`1256-1314`).
10. Deposit `config.deposit_amount * deposit_scale * dialect.knobs["trail_scale"]` (`1328-1330`).
11. `_run_simulation` — Jones 2010 agents on an 80×80 wrap grid, origin biased to weighted food cluster (`689-806`, `1332-1343`).
12. Marching-squares contours → Chaikin-smoothed SVG paths (`1434-1491`). **Vein `<path>` elements have no `data-role`.**
13. Food nodes: halo / shell / core (`data-role="physarum-node-*"`) (`1493-1571`). Satellites (`1573-1600`).
14. Always append `dialect_group_markup(dialect)` (`1602`). Overlay origin **(40, 742)** [`accretion.py:48`](../../../scripts/art/shared/accretion.py).

Config ([`physarum.py:57-79`](../../../scripts/art/physarum.py)): `grid_resolution=80`, `contour_levels=6`, `agent_base=200`, `agent_scale=50`, `food_base=5`, `food_scale=2`, `sim_steps_base=80`, `sim_steps_scale=40`, `max_elements=25_000`.

## Finding

Physarum already maps repos to food nodes, stars to `nutrient_scale`/radius, commits to `trail_scale`/deposit, followers to `vein_gain`/extra agents, and always draws the mycelial overlay. The published GIF path (`timeline=False` + low snapshot maturity) still **gates veins until `growth_mat > 0.05`**. First-repo t0 (`compute_maturity ≈ 0.01`) is a dim spore plus one isolated node — not a transport network. A1 stills are extra-stale (spore-only, pre node-floor). SMIL early frames remain spore-only, and `maturity=0.08` can draw veins **without** nodes. Followers are non-monotonic on vein path count when veins exist. Tests certify overlay ticks, node presence, and star radius — not a learnable four-channel network.

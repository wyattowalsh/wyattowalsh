### Distinct peaks (the Dge1 leftover)

Plan text: “keep distinct peaks; colonies=followers.” A1 did not flag unreadability, but the GIF contract works against distinctness:

1. **Language clustering is the layout.** `strategy="language_cluster"` (`791`). Python/Jupyter → data quadrant (0.25, 0.30); Go/Rust/C → systems (0.25, 0.70); JS/TS → web (0.75, 0.25) ([`visual.py:178-208`](../../../scripts/art/shared/visual.py)). Same-language repos jitter inside one cluster.
2. **Timelapse skips spacing.** `optimize_placement(..., min_spacing=70.0 * crowding_scale)` only when `not timelapse_contract` (`805-815`). `test_render_state_skips_set_reoptimization` **requires** that skip ([`test_living_art_render_state.py:341-361`](../../../tests/test_living_art_render_state.py)). `test_genetic_keeps_repo_peak_positions_stable_under_render_state` (`376-393`) freezes `genetic-peak-core` xy — good for growth, bad if the frozen layout is packed.
3. **Colony terrain is extra elevation around every peak** (`942-952`). Raising `colony_gain` (followers) **fills the saddles** that keep peaks distinct. That fights the plan mapping.
4. **Terraces + ridges.** Older repos get broader σ (`156-168`, `212-239` test). Affinity ridges (`990-1022`) connect topic-siblings.
5. **Crowding shrinks spacing.** `crowding_scale = max(0.42, 1/sqrt(n/10))` (`672-675`) also shrinks `sigma_grid` (`868-871`). Dense same-language sets still start in one quadrant.

Do **not** re-enable per-frame `optimize_placement` on `render_state` — peaks would wander. Distinctness has to come from a **stable** visual plan (hash / phyllotaxis / reserved slots), not a late overlap solver.

Genetic already maps repos → peaks, stars → `peak_scale`/Gaussian height, commits → `generation_gain`/generation count, followers → `colony_gain`/micro-colonies, and always draws the fitness overlay. t0 with the first repo is **not** an empty field: one `genetic-peak-core` exists. The ship picture still fails the plan target:

- The **peak is faint** (core op 0.20, glow 0.07) under a **pop_base=30 swarm** (37 dots at op 0.29).
- **Colonies are almost invisible** (op 0.04) and also stamp elevation that **merges** neighboring peaks.
- **Distinctness is not enforced** on the GIF contract: language-cluster layout + skipped `optimize_placement` + ridges + colony terrain. Same-language repos can collapse — the ferrofluid-class failure, not an empty t0.
- Isolation tests certify **root attrs** (`data-colony-*`, `data-generations`), not on-canvas ink. Stars have **no** isolation test.
- Dual clocks (streaks/PRs/traffic) move gens/pop independently of the four knobs.

A1’s “overlay + peaks grow” is true of the register and of peak **count**. It is not a learnable four-channel landscape.

## `auth spotify-refresh-token`

The helper authorizes the music card and writes the refresh token to `spotify_refresh_token.txt` with owner-only permissions. Set `SPOTIFY_CLIENT_ID` and `SPOTIFY_CLIENT_SECRET` in your environment and register the default redirect URI, `http://127.0.0.1:8888/callback`, in your Spotify app.

```bash
uv run readme auth spotify-refresh-token
```

For IPv6, pass `--callback-host ::1` and register `http://[::1]:8888/callback`. The helper accepts `localhost` as CLI input and uses the IPv4 loopback literal in Spotify requests. The music card requests both `user-read-recently-played` and `user-top-read`.

For manual authorization, open the URL this command displays while its callback listener waits:

```bash
uv run readme auth spotify-refresh-token --no-open-browser
```

On success, the CLI prints the file path and a masked preview. Store the file contents in the `SPOTIFY_REFRESH_TOKEN` Actions secret. Use `--output <path>` to choose a different local file.

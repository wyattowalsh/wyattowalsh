### `generate()` pipeline (`scripts/art/topography.py:619-4121`)

Contract matches `scripts/art/AGENTS.md`: `generate(metrics, *, seed, maturity) -> str`. Extra kwargs: `chrome_maturity`, `timeline=True` (default), `loop_duration=60`, `reveal_fraction=0.93`. **CI/GIF path forces `timeline=False`.**

1. `is_monotonic_timelapse_metrics` then `resolve_render_metrics` then `build_style_dialect("topo", metrics)` (`629-631`).
2. Maturity: explicit or `compute_maturity`. **`growth_mat = 1.0` if timeline else `mat`** (`635`). Published GIFs therefore take the low-maturity fade / `_static_accretion_signal` path.
3. World palette via `compute_world_state` + `_build_world_palette_extended` (`639-648`).
4. Seed hash + numpy RNG + two `Noise2D` (`669-672`).
5. Repos: `order_repos_for_visual_plan` over **the full `repos` list** (`690-697`). No `select_primary_repos` / `MAX_REPOS=10` cap. Dense portfolios keep every `repo-peak` ([`tests/test_topography_timeline.py:340-367`](../../../tests/test_topography_timeline.py)).
6. Dialect knobs pulled immediately: `settlement_gain`, `settlement_scale = 0.70 + 1.20 * gain`, `settlement_mark_count = 0` or `1 + round(4 * gain)` (`710-719`).
7. Terrain grid (`1075-1106`): FBM base + macro relief + ridges. Octave count `3 + total_commits//2500 + round(2 * contour_gain)` (`1089-1094`).
8. **Repos as hills** (`1108-1253`): hash + repulsion; PSO skipped under the timelapse contract (`1146`). **`peak_h = 0.15 + star_frac * 0.6` where `star_frac` is min–max of *this frame’s* per-repo stars** (`1194-1200`). Width from relative `age_months`. Language texture from `LANG_TERRAIN`.
9. Topic place-names (`1255-1384`), then monthly-contribution ridgeline (`1386-1430`, height `intensity * 0.18`).
10. **Central peak always added**, height from **repo count** not stars: `0.45 + 0.25 * min(1, n/(n+2))` (`1432-1455`). Comment: “always the tallest.”
11. Rivers from saddles between star-sorted peaks (`1457+`); forks also bump river count (`1458`).
12. SVG root gets settlement + dialect `data-*` (`1753-1769`). Elevation hypsometric fill (`1896-1918`). Index/normal contours (`2197-2309`). Spot heights (`2388-2437`). `repo-peak` landmarks (`2686-2794`). Settlement symbol (`2939-3038`). Overlay last (`4119`).

Static opacity: `_static_accretion_signal` floor `0.18` (`991-1017`); `_timeline_style` writes `opacity="{max(0.03, opacity * static_signal)}"` (`1028-1035`). Newest landmarks in a window sit at `reveal_frac≈1` → signal **0.108**.

Why stars lose to contours:

1. **`prominence_scale` is not terrain.** Elevation uses relative `star_frac` (`1194-1200`). Isolating total stars with a proportional per-repo split (`stars // (repos-index)` in [`_accretion_metrics`](../../../tests/test_living_art_media.py:1159)) keeps min–max `star_frac` at 0 and 1, so `peak_h` is **unchanged**.
2. **Central peak ≥ typical repo hill.** t0 central height `0.533` vs repo `peak_h=0.45` (single-repo `star_frac` defaults to 0.5). Contours ring the center blob.
3. **Index contours never fade** (`2223`). Landmark fill opacity is `0.65 * static_signal` (`2765`) → 0.07–0.14 on early/newest peaks.
4. Settlement is parented to the **starriest** repo’s `_timeline_style` (`2943-2952`). On the A1 spine that host is also the newest, so t1/t2 settlements stay at group opacity 0.103 no matter how large `settlement_gain` gets.

## Finding

Topography already wires the four-channel dialect, plants a t0 `repo-peak` plus an outpost, and grows overlay ticks t0→t2. Stars are leased as `prominence_scale` but that knob only fattens landmark circles; hill height is a within-frame min–max, so total stars do not raise summits. Contours (commits, plus a followers leak) and a repo-count central peak own the map. Followers are leased as `settlement_gain` and extra dots, but the settlement group is opacity-gated by the starriest (often newest) repo’s static signal (~0.10) and starts at sub-pixel radius. Tests currently certify the caption and settlement **attributes**, which is exactly what Dto1 must stop relying on.

## Requirements

| Requirement | Version |
|---|---|
| Python | 3.13+ |
| [uv](https://docs.astral.sh/uv/) | latest |
| GitHub Token | PAT with `read:user`, `public_repo` |

<Callout type="info" title="macOS extras">
For QR code generation, you also need Cairo: `brew install cairo`. Set `DYLD_LIBRARY_PATH=$(brew --prefix cairo)/lib:$DYLD_LIBRARY_PATH` before running.
</Callout>

## Clone

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_USERNAME.git
cd YOUR_USERNAME
```

<Callout type="idea">
This is a GitHub profile README repo — your username is the repo name. See the [Fork & Repurpose guide](/docs/getting-started/fork-and-repurpose) for full setup.
</Callout>

## Install

The project uses **optional extras** — install only what you need:

```bash title="All locked development and generation dependencies (recommended)"
uv sync --locked --all-extras
```

```bash title="Or use the CLI"
uv run readme dev install
```

<Callout type="idea">
`uv sync --locked --all-extras` installs format, lint, test, and all generation
extras from the committed lockfile in one shot. For CI or minimal setups, use
`uv sync --locked` for core only.
</Callout>

## First run

Generate a default config, then run the full pipeline:

```bash title="1. Create config.yaml with all defaults"
uv run readme config generate-default --path config.yaml
```

```bash title="2. Preview the config"
uv run readme config view --path config.yaml
```

```bash title="3. Generate the SVG banner"
uv run readme generate banner --config-path config.yaml
```

```bash title="4. Generate a QR code"
uv run readme generate qr --config-path config.yaml
```

```bash title="5. Build both starred-repository inputs"
export GITHUB_TOKEN="<token>"
uv run python -m scripts.starred_lists \
  --owner YOUR_USERNAME \
  --languages-output .github/assets/languages.md \
  --topics-output .github/assets/topics.md \
  --topic-threshold 500
```

```bash title="6. Generate the topics word cloud"
uv run readme generate word-cloud \
  --config-path config.yaml \
  --from-topics-md \
  --output-path .github/assets/img/wordcloud.svg
```

<Callout type="warn">
The starred-list token is read from `GITHUB_TOKEN`; there is no token argument.
List generation validates every GraphQL page and publishes the language/topic
pair transactionally. Word-cloud generation exits nonzero when an explicitly
requested source is missing, empty, or produces no output, so fix the input
instead of relying on an older SVG.
</Callout>

## Environment variables

| Variable | Required | Purpose |
|---|---|---|
| `GITHUB_TOKEN` | For metrics/art | GitHub API authentication |
| `LOG_LEVEL` | No | Loguru log level (default `INFO`) |
| `DEBUG_MODE` | No | Enable verbose debug logging |

Set them in your shell or a `.env` file (python-dotenv is not included — export manually or use `direnv`).

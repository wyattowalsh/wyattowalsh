## Module

`scripts/qr.py` — uses `segno`, `qrcode-artistic`, and Pillow. CairoSVG and the
system Cairo libraries support artistic SVG-background rendering.

<Callout type="warn" title="System dependency">
Artistic SVG-background rendering requires Cairo (macOS: `brew install cairo`).
Set `DYLD_LIBRARY_PATH=$(brew --prefix cairo)/lib:$DYLD_LIBRARY_PATH` before a
background-backed run. Plain QR generation with no background does not use that
rendering path.
</Callout>

## What it generates

A PNG file containing:
1. A QR code encoding your **vCard** contact data (`VCardDataModel` from config)
2. An optional **SVG background** composited behind the QR modules; with no background, Segno writes a standard QR PNG
3. Configurable **error correction level** (H = 30% recovery)

## Configuration

Set in `config.yaml` under `qr_code_settings`:

```yaml
qr_code_settings:
  output_filename: qr.png
  output_dir: .github/assets/img
  default_background_path: null
  default_scale: 25
  error_correction: H   # L | M | Q | H
```

## CLI

```bash
uv run python -m scripts.cli generate qr \
  --config-path ./config.yaml \
  --output-path .github/assets/img/qr.png \
  --qr-scale 25 \
  --qr-background-path .github/assets/img/icon.svg
```

The generator removes the exact prior target before rendering and accepts only
a freshly written regular PNG that Pillow can verify. The CLI also requires the
renderer to return the requested path. A no-op renderer, invalid/partial image,
unexpected path, or save failure exits nonzero and cleans the target instead of
reusing stale bytes.

The configured `output_filename` is a bare, lowercase `.png` filename: it
cannot contain a directory, parent component, absolute path, or Windows drive.
Use CLI `--output-path` when selecting a different output directory; its final
filename is subject to the same `.png` rule. Validation happens before any
existing target is removed.

## vCard encoding

The QR encodes a vCard 3.0 string built from `VCardDataModel`:

```
BEGIN:VCARD
VERSION:3.0
FN:Wyatt Walsh
N:Walsh;Wyatt;;;
ORG:Personal Portfolio Project
TITLE:Developer & Tech Enthusiast
TEL;TYPE=WORK,VOICE:2096022545
EMAIL;TYPE=INTERNET:wyattowalsh@gmail.com
URL;TYPE=WORK:https://w4w.dev
END:VCARD
```

## Error correction levels

| Level | Recovery capacity | File size |
|---|---|---|
| `L` | ~7% | Smallest |
| `M` | ~15% | Small |
| `Q` | ~25% | Medium |
| `H` | ~30% | Largest (default) |

Use `H` when embedding a background image — the image covers some modules.
